# 디자인 시스템

스토어에서 반복되는 값은 CSS 변수로 정의하고, 반복되는 조작과 표현은 작은 UI 컴포넌트로 공유한다. 화면 구성은 CSS Modules로 격리한다. 상품 분류·가격·검색 조건은 공통 UI에 포함하지 않는다.

## 토큰 구조

`src/styles/tokens.css`에서 기본 값과 의미를 분리한다. 예를 들어 `--purple-500`은 색상 값이고, `--color-brand`는 브랜드를 표현하는 역할이다. 컴포넌트는 의미 토큰을 사용하므로 브랜드 색을 바꿀 때 개별 메뉴나 버튼을 수정하지 않는다.

| 영역 | 기본 값 | 적용 |
| --- | --- | --- |
| 브랜드 | `#7F77DD` | 로고, 활성 메뉴, 선택된 페이지 |
| 테두리 | `#E9EAEC` | 상품 이미지 영역 |
| 입력 테두리 | `#CED0D4` | 검색창 기본 테두리 |
| 아이콘·보조 본문 | `#636873` | 헤더 아이콘, 보조 안내 |
| 보조 텍스트 | `#979CA5`, `#B2B6BD` | 분류, 정가, 푸터 |
| 가격·배너 강조 | `#FA622F` | 할인율, 배너 소개·아이콘·CTA |
| 타이포 | Pretendard, 12·14·16·18·24px | 설명, 분류, 상품명·가격, 메뉴, 로고 |
| 본문 행간 | 160% | 상품 정보와 공통 텍스트 |
| 모서리 | 4·6px | 버튼, 입력창·상품 이미지 |
| 간격 | 4px 단위 기본 척도 | 컴포넌트 내부 간격 |
| 레이아웃 | 1280px 컨테이너, 250×320px 이미지, 행 간격 36px | 데스크톱 상품 목록 |

시안의 50px 목록 여백과 46px 페이지 이동 간격은 레이아웃 토큰으로 따로 둔다. 배너의 강조색은 `--orange-500`을 공유하고, 어두운 배경의 보조색과 고유한 타이포·장식 치수는 배너 모듈에 둔다. 모든 숫자를 전역 토큰으로 만들지 않는다.

기본 색상은 Figma의 레이어 속성에 표시된 HEX 값으로 대조한다. 페이지 이동의 outline 버튼은 글자와 테두리에 모두 브랜드 색을 사용하며, 검색창 테두리는 별도 의미 토큰으로 분리한다. hover 배경·포커스 링·비활성 투명도는 상호작용을 위해 추가한 상태 값이다.

## 공통 컴포넌트

| 컴포넌트 | 책임 | 사용 상태 |
| --- | --- | --- |
| Button | 텍스트 버튼과 네이티브 버튼 속성 전달 | primary·outline·ghost, hover·focus-visible·disabled |
| IconButton | 아이콘 조작과 필수 접근성 이름 | plain·outline·floating, 44px 조작 영역 |
| Icon | SVG를 CSS mask로 표시 | currentColor, 16·24px |
| TextField | label과 input 연결, 앞뒤 보조 요소 배치 | focus-within·disabled·aria-invalid |
| Badge | 짧은 분류와 상태 텍스트 | muted·brand·inverse |

공통 컴포넌트는 상품 조회, 라우터, 장바구니 저장소에 의존하지 않는다. 카드와 검색 영역은 `features/books/ui`에서 조합한다. 컴포넌트마다 사용하지 않는 다형성 API나 외부 UI 라이브러리는 추가하지 않는다.

## 반응형과 접근성

- 1100px 이상은 4열, 768~1099px은 3열, 767px 이하는 2열로 표시한다.
- 1440px에서 컨테이너 좌우 여백은 80px이다. 좁은 화면에서는 카드 너비가 가용 공간에 맞춰 줄어든다.
- 900px 미만에서는 헤더 메뉴를 두 번째 줄로 옮긴다. 검색창은 768px 미만에서 전체 너비를 사용한다.
- 상품 이미지는 25:32 영역을 먼저 확보하고 `object-fit: contain`으로 원본 비율을 보존한다.
- 담기 버튼은 포인터 hover와 키보드 focus 시 표시하고, hover를 지원하지 않는 기기에서는 항상 표시한다.
- 아이콘은 장식으로 처리하고 버튼의 이름으로 동작을 설명한다. 상품 이미지는 상품명을 대체 텍스트로 사용한다.
- 본문 바로가기, 의미 있는 제목 구조, 포커스 표시를 제공한다. 동작 줄이기 설정에서는 전환 시간을 0으로 설정한다.

## 현재 화면과 검증 범위

목록은 Supabase에서 검색·분류 조건에 맞는 교재와 정확한 전체 개수를 조회한다. 정적 데이터는 테스트 fixture에만 남겨 두었다. 페이지 크기는 12개이며 현재 페이지는 브랜드 배경으로 표시하고 페이지 번호는 실제 링크로 제공하며 이전·다음은 첫·마지막 페이지에서 비활성화한다.

조회 중에는 카드와 같은 그리드·이미지 비율의 스켈레톤을 표시한다. 동작 줄이기 설정에서는 스켈레톤 애니메이션을 끈다. 빈 목록과 실패 안내를 구분하고 다시 시도 버튼을 제공한다. 표지 로딩에 실패해도 확보한 영역과 상품명·가격을 유지한다.

검색은 Enter·검색 버튼으로 적용하고 X 버튼으로 초기화한다. 필터는 `aria-pressed`, 현재 페이지는 `aria-current`로 선택 상태를 전달한다. 로딩 중에도 검색·분류 조작을 유지한다. 담기 버튼을 누르면 수량 배지와 토스트를 갱신한다. 저장 상태 복구 전에는 담기 버튼을 비활성화한다. 헤더 메뉴는 표시 전용이고 스토어의 활성색과 hover·focus 효과를 제공한다. 배너 CTA와 본문 바로가기는 실제 교재 영역으로 이동한다.

장바구니 패널은 데스크톱에서 520px, 519px 이하에서 화면 전체 너비를 사용한다. 합계는 브랜드색으로 강조하고 수량·삭제·닫기 버튼은 최소 44px 조작 영역을 확보한다. 목록만 내부 스크롤하며 제목과 합계 영역은 유지한다. 빈 상태·가격 확인 중·실패·상품 누락·보관 실패를 별도 문구로 표시한다.

배너는 배경 이미지 위에 실제 텍스트와 SVG 아이콘을 배치한다. 문구는 1280px 컨테이너에 맞추고 배경은 배너 하단까지 이어진다. 배경 이미지의 최대 폭은 1760px로 제한해 초광폭 화면에서 책이 과하게 확대되지 않도록 하고, 이미지 바깥쪽은 배너 바탕색으로 자연스럽게 연결한다. 데스크톱은 최소 600px 높이를 확보하되 콘텐츠에 맞춰 늘어난다. 제목은 64px·700, 보조 제목은 최대 48px·300, 설명은 18px다. 실전 적중·난이도별 구성·검증된 결과에는 각각 crosshair·chart-bar·trophy 아이콘을 사용한다.

767px 이하에서는 문구·특징·CTA 아래에 교재 이미지를 배치하며 배경은 화면 양끝까지 확장한다. 상단 40px, 문구와 이미지 사이 32px, 조작부 아래 32px 여백을 확보하고 제목 크기와 줄바꿈은 가용 너비에 맞춘다. 모바일 조작부는 이미지 아래에 두고, 데스크톱에서는 받침대 위에 배치해 책과 문구를 가리지 않는다.

캐러셀 조작 버튼은 44px 영역과 접근성 이름을 제공한다. 현재 번호는 자동 재생 중 반복 낭독하지 않고, 정지 상태의 수동 조작에서는 변경을 알린다. hover·내부 포커스·숨겨진 탭에서는 재생을 멈추며 동작 줄이기 설정에서는 자동 재생을 시작하지 않는다. 명시적 정지는 포커스가 나가도 유지된다.

자동·수동 이동은 650ms의 좌우 전환을 사용하며 처음과 마지막 사이에도 이동 방향을 유지한다. 조작부는 전환 중에도 같은 위치와 포커스를 유지한다. 나가는 슬라이드는 접근성 트리와 키보드 탐색에서 제외하고, 동작 줄이기 설정에서는 애니메이션 없이 바로 전환한다.

가격 규칙은 Vitest로 할인 없음·반올림·판매가 0원·정가 0원·동일 가격을 검증한다. Playwright는 1440px의 배치 치수, 768·390·360px의 열 개수와 가로 넘침, 폰트·자산 로딩, hover·focus와 터치 버튼 표시를 확인한다. 배너는 500·905·1200·2841px에서도 배경 영역과 문구·조작부 여백을 확인한다. 캡처는 육안 비교용이며 픽셀 단위 동일성을 보장하는 스냅샷 테스트는 아니다.
